# Learning Journey

An iOS app that helps you build a daily learning habit. Set a learning goal, log the days you learned, and keep your streak going.

## Main Features

- Set a learning goal (what you want to learn) and choose its duration: a week, a month, or a year
- Log each day as "Learned" to build your streak
- Freeze a day without losing your streak (2 freezes per week, 8 per month, 96 per year)
- Streak resets if you spend more than 32 hours without logging a day or using a freeze
- Calendar view with all your previous learned and frozen days
- Update your learning goal at any time (your streak starts over)
- Set a new goal when you complete or miss the current one

## Technologies

- Swift and SwiftUI
- MVVM architecture
- UserDefaults for local storage
- Liquid Glass design (iOS 26)
